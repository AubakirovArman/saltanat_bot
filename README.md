# saltanat_bot_python

Это приложение предназначено для визуального конструирования и запуска торговых стратегий. Интерфейс построен на Dash и Flowfunc, что позволяет объединять готовые узлы в логическую цепочку и выполнять её в реальном времени.

## Требования
- Python 3.11 и выше
- подключение к сети (для получения рыночных данных и работы с биржами)

## Установка зависимостей
```bash
pip install dash dash-bootstrap-components flask plotly requests pandas flowfunc numpy pybit python-binance
```

Модуль `extended_flowfunc` расширяет возможности стандартной библиотеки `flowfunc` и предоставляет дополнительные атрибуты для кастомизации узлов.

## Запуск
```bash
python main.py
```
или
```bash
python3 main.py
```
После запуска приложение будет доступно по адресу `http://127.0.0.1:8050`.

## Возможности
- Графический редактор нод для создания пользовательских логик
- График котировок в стиле TradingView с возможностью добавления индикаторов
- Поддержка основных биржевых операций через Binance и Bybit
- Отправка уведомлений в Telegram

## Основные страницы
- `/nodes` — визуальный редактор логики. Позволяет добавлять, сохранять и исполнять собственные схемы.
- `/charts` — страница с графиком и редактором стратегии на основе нод.

## Структура проекта
- `main.py` — точка входа и регистрация маршрутов
- `modules/` — реализация страниц `/nodes` и `/charts`, а также логика работы редактора
- `extended_flowfunc/` — расширение библиотеки Flowfunc для кастомизации узлов
- `ui/` — элементы интерфейса (например, навигационная панель)

## Быстрый старт
1. Установите зависимости
2. Запустите `python main.py`
3. Перейдите на `/nodes` и соберите простую логику из доступных узлов
4. На странице `/charts` выберите торговую пару, таймфрейм и запустите стратегию
