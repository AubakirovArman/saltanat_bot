# saltanat_bot_python

Проверено на python3.11

**Установка зависимостей**
```
pip install dash dash-bootstrap-components flask plotly requests pandas flowfunc numpy pybit python-binance
```

**Запуск**
```
python main.py
```
или
```
python3 main.py
```

## Страницы
- `/nodes` — визуальный редактор логики.
- `/charts` — редактор графиков в стиле TradingView с узловой системой Flowfunc.
